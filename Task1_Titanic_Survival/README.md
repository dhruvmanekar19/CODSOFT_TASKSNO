# Titanic Survival Prediction

## Project Description
This project uses the Titanic dataset to build a Machine Learning model that predicts whether a passenger survived or not.

The dataset contains passenger information such as age, gender, passenger class, fare, and other relevant details.

## Objective
To build a classification model that predicts:

- 0 → Passenger Did Not Survive
- 1 → Passenger Survived

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model

The Logistic Regression algorithm was used to train the model.

## Project Workflow

1. Load the Titanic dataset
2. Explore and preprocess the data
3. Handle missing values
4. Encode categorical variables
5. Visualize the data
6. Split the dataset into training and testing sets
7. Train the Logistic Regression model
8. Evaluate the model using accuracy and classification metrics
9. Generate a confusion matrix
10. Predict survival for a new passenger

## Results

The model achieved approximately **80% accuracy** on the test dataset.

## Visualizations

The project includes:

- Survival Distribution
- Survival by Gender
- Survival by Passenger Class
- Confusion Matrix
